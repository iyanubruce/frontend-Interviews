# Generate Table

**Difficulty:** Easy · **Duration:** ~15 min · **Topics:** A11y

> Source: [generate-table](https://www.greatfrontend.com/questions/user-interface/generate-table/vue)

## Description

Generate a table of numbers given the number of rows and columns.

![Generated table of 4 rows by 5 columns](https://www.gfecdn.net/img/questions/generate-table/generate-table-example.webp)

### Requirements

1. The user enters the number of rows and columns in a form.
2. When the form is submitted, a table with the respective number of rows and columns is generated.
3. The table contains rows x columns cells, each containing a number in the sequence from 1 to (rows x columns).
4. Fill the table column by column, alternating between top-to-bottom and bottom-to-top for each successive column.
